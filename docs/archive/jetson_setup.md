# Jetson 到着後セットアップ手順（初心者向け・一歩ずつ）

> 心構え：**初回起動は「新しいスマホの初期設定」と同じレベル**です。
> 画面の案内に従うだけ。一度やれば終わり。怖くないし、詰まったら僕を呼べばいい。

---

## STEP 0. 箱が届いたら中身チェック

だいたいこれが入ってるはず（キットによる）：

- [ ] Jetson 本体（ボード or ケース入り）
- [ ] 電源（USB-C か 丸いDCプラグのアダプタ）
- [ ] microSD カード（別で買ったKIOXIAを使う。最初から挿さってることも）
- [ ] WiFiアンテナ（付いてれば）

**自分で用意するもの：**
- HDMIケーブル + モニタ（テレビでもOK）
- USBキーボード + マウス
- ネット（WiFi または LANケーブル）

---

## STEP 1. 電源を入れる前の接続

1. microSDカードを Jetson のスロットに挿す（既に挿さってたらそのまま）
2. HDMIケーブルでモニタに繋ぐ
3. USBキーボードとマウスを挿す
4. 最後に電源を挿す（＝これで起動する）

---

## STEP 2. 画面を見て、どっちか判断

**A) Ubuntuの初期設定ウィザードが出た** → 当たり。OSが入ってます。
   - 言語（English か 日本語）、地域、キーボード、ユーザー名・パスワードを設定
   - スマホの初期設定と同じノリで進めればOK
   - WiFiもここで繋げる

**B) 画面が真っ黒 / 何も映らない / 変な文字だけ** → OSが入ってないかも。
   - ここは自力でやらなくていい。**この時点で僕を呼んでください。**
   - microSDにJetPack（JetsonのOS）を焼く作業を一緒にやります（PCで20〜30分）

---

## STEP 3. デスクトップが出たら、端末(Terminal)を開く

Ubuntuのデスクトップが出たら、`Terminal`（黒い画面のアプリ）を開いて、まずネットとアップデート：

```bash
ping -c 3 google.com          # ネット繋がってるか確認
sudo apt update && sudo apt upgrade -y   # 最新化（時間かかる）
sudo apt install -y git python3-pip python3-venv
```

---

## STEP 4. GitHubからコードを持ってくる

```bash
cd ~
git clone https://github.com/＜あなたのユーザー名＞/osouji-robot.git
cd osouji-robot
```

これで、PCで作った一式がJetsonに載ります。（「gitで運ぶ」がここで効く）

---

## STEP 5. ここから先は一緒に

- Python環境つくって依存インストール
- gesture / voice を動かして初の動作確認
- ROS2 + Gazebo へ

STEP 4まで来たら「clone できた」と言ってください。そこから続きをやります。

---

## メモ（後回しでOK）

- 8GBモデルなので、動かし始めたら電力・メモリモードの調整（`nvpmodel` / `jetson_clocks`）をやると安定します。**最初は気にしなくていい。**
- 詰まったら、画面のスクショか写真を貼るのが最速。文字で説明しづらい所は見れば一発で分かります。
